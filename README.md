# QuickerKeys

AutoHotkey v2-verktøy for å forenkle arbeidsflyt mellom Trio og Service Manager.

## Verktøy
- **Tekstflyt:** Personlige tekstsnarveier lagret i Excel.
- **SM Kontakt:** Overføring av brukernavn/kundenummer fra Trio til Service Manager.
- **Vindusbytter:** Hurtigtaster for opptil fire vinduer.

Programmet lagrer lokale innstillinger i `Innstillinger/QuickerKeys.ini`, tekstsnarveier i `Tekstflyt/` og loggfiler i `Logg/`. Ved første oppstart forsøker det å importere tidligere oppsett uten å slette originalene.
